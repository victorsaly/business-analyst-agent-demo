The team

Capstone 2 of the Agentic AI Workshop 2026 was built as a team. These are the people who made it.

Victor Saly

Project Manager

Victor is a software engineer at Storm Software Systems in Watford, with a long background in .NET web development, search and content platforms. He is a certified Umbraco Expert and Elasticsearch Engineer. Lately he has moved into AI products: he holds Microsoft's AI Product Manager certificate and completed London Business School's Implementing Generative AI course. On this project he built the agent, the site and the tooling behind them.

Akashdeep Nijjar

modified agent

Changes to Capstone Project2: -added verification function that takes the user query and checks whether all info necessary for charts are there (i.e. prompt give me the overview of cogs for the entire year - this can be a bar plot grouped by region (but user hasn’t specified region) or line graph showing trend per week ) in an ambiguous query like this the agent should not assume and goes back to ask the user what kind of plot is preferred - added matching rule in rulebook for this - accessible charts for vision impaired
